# 차곡 내용 보관(게시 안 함)

2026-10-07 종인님 결정: "차곡은 아직 출시 전인데 주량체커 내용만으로 나가고, 차곡 내용은 차곡에서 나갈 때 등록하게 해."

- 이 폴더의 privacy.md·terms.md·support.md는 **두 앱(주량체커·차곡) 구조 정리판**이다(공통 본문 + 앱별 단락/표 + 차곡 추가 조항). build.py는 `src/*.md`만 빌드하므로 여기 있는 파일은 게시되지 않는다.
- 차곡 출시(심사 제출) 전에 차곡 세션이 이 파일을 기준으로 `src/`에 차곡 내용을 다시 넣는다 — 그사이 `src/`의 주량체커 내용이 바뀌었으면 그 변경을 살려 합칠 것.
- 함께 바꿀 것: build.py `OPERATOR`의 운영자 문장(지금 한 앱 기준), App Store Connect 차곡 방침·지원 URL.
