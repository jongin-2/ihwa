# 차곡 내용 준비판(게시 안 함)

2026-10-07 종인님 결정: "차곡은 아직 출시 전인데 주량체커 내용만으로 나가고, 차곡 내용은 차곡에서 나갈 때 등록하게 해."
2026-10-14 종인님 "이대로 해"(차곡 FEEDBACK #335) — 이 폴더의 privacy.md·terms.md는 **지금 공개판(주량체커·응원석, src/)에 차곡 문장을 더한 게시 직전판**이다.
build.py는 `src/*.md`만 빌드하므로 여기 있는 파일은 게시되지 않는다.

차곡 심사 제출 때(차곡 세션):
1. 그사이 `src/`가 바뀌었으면(`git diff <이 파일을 만든 커밋> -- src/`) 그 변경을 이 준비판에 먼저 합친다.
2. 지금 판을 `src/archive/<문서>/<게시 날짜>.md`로 보관(README "이전 판" 절차) → 이 파일을 `src/`로 복사 → 최종 수정일을 그날로.
3. build.py → 푸시 → 공개 페이지 확인, 응원석·주량체커 세션에 알림.
support.md(10-09 지원 페이지 폐지)는 쓰지 않는다.
