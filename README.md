# ihwa — 공개 고객 지원·개인정보처리방침

주량체커(DrinkChecker)·차곡(Chagok) 두 앱이 함께 쓰는 **공개 페이지**만 둔다(App Store Support URL·개인정보 처리방침 URL).

- 고객 지원: https://jongin-2.github.io/ihwa/support/
- 개인정보처리방침: https://jongin-2.github.io/ihwa/privacy/

원문은 `src/*.md`, `python3 build.py`로 `docs/`를 만든다(GitHub Pages가 `docs/`를 게시). **방침을 고치면 각 앱 저장소의 앱 안 문서(`legalContent.ts`, `legal.ts`)도 같이 고친다** — 어긋나면 안 된다(Notion 사본은 2026-09-27 폐기).
