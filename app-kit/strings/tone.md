# 말투 기준(모든 앱·사이트·스토어)

11-10 종인님 "이화웹내 말투 통일해" · "스토어도 해요체로 통일" · "정석에 맞추어". 정석 = 플랫폼(Apple) 그 나라 공식 문서·페이지가 쓰는 높임. 한 언어 안에서는 한 가지만 쓴다.

| 언어 | 기준 | 근거(11-10 코어가 apple.com·support.apple.com에서 대명사 세기) |
|---|---|---|
| ko | 해요체(~예요/~어요/~세요). 약관·방침 본문만 합니다체 | 종인님 결정 |
| id | Anda (kamu·-mu 쓰지 않음) | apple.com/id/iphone Anda 76·kamu 0, app-store Anda 64·kamu 0, Microsoft Indonesian Style Guide |
| tr | siz (-iniz·-in 꼴 — "deneyin", "hesabınız") | apple.com/tr/iphone 존대 124·친근 0, support.apple.com/tr-tr 151·0, app-store 53·0 |
| fr | vous | apple.com/fr/iphone vous 199·tu 0 |
| ru | вы | support.apple.com/ru-ru вы 37·ты 0 |
| de | du | apple.com/de/iphone du 182·Sie 3, app-store 85·0 |
| es | tú | apple.com/es/iphone 40·0 |
| it | tu | apple.com/it/iphone 75·0 |
| pt-BR | você | apple.com/br/iphone 38·0 |
| ja·zh·vi | です・ます / 대명사 생략 / bạn — 한 가지 | 섞임만 확인 |

- 새 언어를 넣을 때는 같은 방법(그 나라 apple.com·support.apple.com 대명사 세기)으로 정하고 이 표에 더한다.
- 앱 세션은 앱 사전·스토어·위치 권한 문구를 이 표에 맞추고, 사이트는 IhwaWeb이 맞춘다.
