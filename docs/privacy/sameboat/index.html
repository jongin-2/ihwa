3. 사용 통계와 외부 요청

앱은 서비스를 개선하는 통계 분석을 위해 Google Firebase Analytics로 서비스 이용 기록과 기기 정보(기기 종류·OS 버전·앱 버전, 앱 설치마다 정해지는 무작위 식별값), IP 주소로 추정한 대략적인 지역(국가·도시 수준, Google이 IP 주소 일부를 가린 뒤 추정)을 자동으로 수집합니다. 이 정보로 이용자를 식별하지 않으며 이름·연락처·광고 식별자와 연결하지 않습니다. 기록한 내용(말풍선, 노선, 위치, 생일, 계정 정보)은 통계에 담지 않습니다. 광고 식별자(IDFA)와 크래시 리포트는 수집하지 않고, 광고나 추적에 쓰지 않습니다.

앱이 아래 외부 서비스에 요청할 때는 일반적인 웹 요청처럼 IP 주소 같은 접속 정보가 그 서비스에 전달될 수 있으며, 운영자는 이를 받거나 보관하지 않습니다.
